# Personal Portfolio Website

## Overview

This project is my personal portfolio website built using HTML, CSS, and a small amount of JavaScript. It was created to showcase my web development skills, projects, and contact information while recreating a design based on a provided Figma layout.

The website is fully responsive and works on desktop, tablet, and mobile devices.

## Features

- Responsive navigation
- Hero section with introduction
- About Me section
- Skills section
- Featured projects with GitHub links
- Contact section
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Projects Included

- JavaScript API Dashboard
- JavaScript Quiz App
- Magia Glory Beta (Python RPG)

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional software or installation is required.

## What I Learned

While building this project I practiced:

- Writing semantic HTML
- Creating responsive layouts with CSS
- Improving page design using Flexbox and Grid
- Organizing a multi-section website
- Building a portfolio to showcase my projects
